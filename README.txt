REXARD / ЕМК — локальный сайт

Запуск: откройте run-local.command, затем http://127.0.0.1:4173/.
Нужен Python 3. Установка npm-пакетов не требуется.
Сервер доступен только на этом компьютере. Остановка: Ctrl+C в терминале.

Ковш и кузов карьерного самосвала состоят из отдельных объёмных деталей.
Прокрутка собирает модель. Доступны вращение, вид «Чертёж», выбор конструкции,
светлая и тёмная темы, карточки четырёх марок стали.
Это иллюстративные модели для сайта, не производственная документация.

Логотип REXARD: рендеры исходной геометрии REXARD_logo_RU_flush_v04.blend,
включая оригинальное начертание и русскую подпись; прозрачный фон.
ЕМК: оригинальные SVG с emk24.ru и официального лендинга компании.
